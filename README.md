# Personal Website & Portfolio

The source code for Sethu Iyer's personal website and portfolio, showcasing research, projects, and professional work in AI, mathematics, and software development.

## Overview

This is a GitHub Pages hosted website that serves as a comprehensive portfolio and professional presence. The site features responsive design, interactive elements, and showcases various projects and research work.

## Features

- **Responsive Design**: Mobile-friendly layout that adapts to different screen sizes
- **Project Portfolio**: Showcase of AI/ML, mathematical research, and software projects
- **Professional Profile**: About section with background and expertise
- **Interactive Elements**: JavaScript-powered interactive components
- **Modern Styling**: Clean, professional aesthetic with CSS3 features

## Structure

- `index.html` - Main landing page and site structure
- `css/` - Stylesheets and design assets
- `js/` - JavaScript functionality and interactive features
- `img/` - Images, photos, and visual assets
- `projects/` - Individual project pages and documentation
- `img_request/` - Image processing and request handling
- `.well-known/` - Site verification and metadata

## Technologies

- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Advanced styling, animations, and responsive design
- **JavaScript**: Interactive functionality and dynamic content
- **GitHub Pages**: Static site hosting and deployment

## Sections

- **About**: Professional background and expertise
- **Research**: Academic work and publications
- **Projects**: Software development and research projects
- **Contact**: Professional contact information and links

## Deployment

The site is automatically deployed via GitHub Pages when changes are pushed to the main branch.

```bash
git add .
git commit -m "Update website content"
git push origin main
```

## Local Development

To run locally:
```bash
# Serve the site locally
python -m http.server 8000
# Access at http://localhost:8000
```
