Prime Euler Activations and ZetaDrop

Core Idea#

The Multiplicative PINN framework applies an arithmetic gate at the loss level:

Lmult=Ldata⋅C(v),L_{\text{mult}}=L_{\text{data}}\cdot C(v),Lmult​=Ldata​⋅C(v),

where vvv measures constraint violation and C(v)C(v)C(v) rescales the optimization landscape. This preserves the main data-gradient direction while adding a structured correction through

∇θLmult=C(v)∇θLdata+Ldata∇θC(v).\nabla_\theta L_{\text{mult}} = C(v)\nabla_\theta L_{\text{data}} + L_{\text{data}}\nabla_\theta C(v).∇θ​Lmult​=C(v)∇θ​Ldata​+Ldata​∇θ​C(v).

The same mechanism can be moved inside the network.

Instead of applying the arithmetic gate only to the final loss, we can apply it to activations, channels, attention heads, LoRA ranks, or experts:

hl+1=σ(Wlhl+bl)⊙Aθ(zl,cl).h_{l+1} = \sigma(W_lh_l+b_l)\odot A_\theta(z_l,c_l).hl+1​=σ(Wl​hl​+bl​)⊙Aθ​(zl​,cl​).

The conceptual mutation is:

loss-level constraint gate⇒layer-level representation gate⇒activation-level spectral gate.\boxed{ \text{loss-level constraint gate} \Rightarrow \text{layer-level representation gate} \Rightarrow \text{activation-level spectral gate}. }loss-level constraint gate⇒layer-level representation gate⇒activation-level spectral gate.​

The resulting object is a Prime Euler activation: a neural nonlinearity whose response is modulated by a finite Euler product.

Prime Euler Gated Activation#

Let PPP be a finite set of primes. Define a positive spectral coordinate

v=softplus⁡(z).v=\operatorname{softplus}(z).v=softplus(z).

The Euler gate is

G(z)=∏p∈P(1−p−τsoftplus⁡(z)).G(z) = \prod_{p\in P} \left(1-p^{-\tau \operatorname{softplus}(z)}\right).G(z)=p∈P∏​(1−p−τsoftplus(z)).

A direct Prime Euler activation is

EulerGate⁡(z)=z∏p∈P(1−p−τsoftplus⁡(z)).\boxed{ \operatorname{EulerGate}(z) = z\prod_{p\in P} \left(1-p^{-\tau \operatorname{softplus}(z)}\right). }EulerGate(z)=zp∈P∏​(1−p−τsoftplus(z)).​

A smoother practical version uses SiLU as the base activation:

SiLU⁡(z)=zσ(z),\operatorname{SiLU}(z)=z\sigma(z),SiLU(z)=zσ(z),

and gates it:

PESiLU⁡(z)=SiLU⁡(z)⋅G(z).\boxed{ \operatorname{PESiLU}(z) = \operatorname{SiLU}(z)\cdot G(z). }PESiLU(z)=SiLU(z)⋅G(z).​

Here PESiLU means Prime Euler Gated SiLU.

The softplus is important because the Euler product naturally wants a nonnegative coordinate:

s=τv.s=\tau v.s=τv.

Thus the activation does not merely ask whether z>0z>0z>0, as ReLU does. It asks which arithmetic spectral coordinate the activation occupies.

Residual PESiLU#

The raw Euler product satisfies

G(0)=0,G(0)=0,G(0)=0,

because each factor becomes 1−1=01-1=01−1=0. For activations, this can over-suppress gradients. A safer version keeps the base activation alive and uses the Euler gate only as a modulation:

ResidualPESiLU⁡(z)=SiLU⁡(z)(1+αG(z)).\boxed{ \operatorname{ResidualPESiLU}(z) = \operatorname{SiLU}(z) \left(1+\alpha G(z)\right). }ResidualPESiLU(z)=SiLU(z)(1+αG(z)).​

This gives:

base activation+prime spectral modulation.\text{base activation} + \text{prime spectral modulation}.base activation+prime spectral modulation.

In practice this is the first version to benchmark, because it preserves the stability of SiLU while injecting a controlled arithmetic response.

Let

measure local violation, salience, uncertainty, curvature, or physics inconsistency. Examples include:

Then define

hl+1=σ(Wlhl+bl)⊙C(vl).\boxed{ h_{l+1} = \sigma(W_lh_l+b_l)\odot C(v_l). }hl+1​=σ(Wl​hl​+bl​)⊙C(vl​).​

with

C(vl)=clamp⁡[max⁡(∏p∈P(1−p−τvl),eγvl),ϵ,M].C(v_l) = \operatorname{clamp} \left[ \max\left( \prod_{p\in P}(1-p^{-\tau v_l}), e^{\gamma v_l} \right), \epsilon, M \right].C(vl​)=clamp​max​p∈P∏​(1−p−τvl​),eγvl​​,ϵ,M​.

This moves the Multiplicative PINN mechanism from global loss space into local representation space. The network does not wait for the final loss to punish constraint violations; it routes information differently through layers depending on constraint compatibility.

Prime-Indexed Sparse Parameters#

The same gate can induce structured sparsity.

Assign each neuron, channel, attention head, LoRA rank, or expert a prime:

p1=2,p2=3,p3=5,p4=7,… .p_1=2,\quad p_2=3,\quad p_3=5,\quad p_4=7,\dots.p1​=2,p2​=3,p3​=5,p4​=7,….

Then gate parameter block θi\theta_iθi​ by

gi(v)=1−pi−τv,g_i(v)=1-p_i^{-\tau v},gi​(v)=1−pi−τv​,

so the effective parameter is

θieff=gi(v)θi.\theta_i^{\mathrm{eff}} = g_i(v)\theta_i.θieff​=gi​(v)θi​.

For small vvv,

pi−τv≈1−τvlog⁡pi,p_i^{-\tau v} \approx 1-\tau v\log p_i,pi−τv​≈1−τvlogpi​,

and therefore

gi(v)=1−pi−τv≈τvlog⁡pi.g_i(v) = 1-p_i^{-\tau v} \approx \tau v\log p_i.gi​(v)=1−pi−τv​≈τvlogpi​.

This means prime-indexed blocks open at rates controlled by log⁡pi\log p_ilogpi​.

There is also an attenuation form:

ai(v)=pi−τv.a_i(v)=p_i^{-\tau v}.ai​(v)=pi−τv​.

ai(v)=pi−τv⇒small-prime core stays active while large-prime tail sparsifies.\boxed{ a_i(v)=p_i^{-\tau v} \Rightarrow \text{small-prime core stays active while large-prime tail sparsifies}. }ai​(v)=pi−τv​⇒small-prime core stays active while large-prime tail sparsifies.​

The opening form gives:

gi(v)=1−pi−τv⇒large-prime refiners activate differently as violation grows.\boxed{ g_i(v)=1-p_i^{-\tau v} \Rightarrow \text{large-prime refiners activate differently as violation grows}. }gi​(v)=1−pi−τv​⇒large-prime refiners activate differently as violation grows.​

ZetaDrop#

ZetaDrop is the dropout-like version of the idea.

Ordinary dropout randomly suppresses units. ZetaDrop suppresses channels according to an Euler-product arithmetic prior:

ZetaDrop⁡(hi)=hi⋅pi−τv.\boxed{ \operatorname{ZetaDrop}(h_i) = h_i\cdot p_i^{-\tau v}. }ZetaDrop(hi​)=hi​⋅pi−τv​.​

This is not random sparsity. It is spectral sparsity.

A channel with a small prime index remains active longer:

2−τv>3−τv>5−τv>7−τv.2^{-\tau v} > 3^{-\tau v} > 5^{-\tau v} > 7^{-\tau v}.2−τv>3−τv>5−τv>7−τv.

Thus the network receives a deterministic hierarchy:

input difficulty or constraint violation⇒prime-indexed parameter budget.\text{input difficulty or constraint violation} \Rightarrow \text{prime-indexed parameter budget}.input difficulty or constraint violation⇒prime-indexed parameter budget.

Low-complexity inputs can use the small-prime core. Harder or higher-violation inputs can activate larger-prime refiners.

αi(x)=gi(x)∑jgj(x).\alpha_i(x) = \frac{g_i(x)}{\sum_j g_j(x)}.αi​(x)=∑j​gj​(x)gi​(x)​.

Spectral Gradient Engine#

The mathematical reason the gate is not an arbitrary nonlinearity is its log-gradient.

For

G(v)=∏p∈P(1−p−τv),G(v)=\prod_{p\in P}(1-p^{-\tau v}),G(v)=p∈P∏​(1−p−τv),

we have

ddvlog⁡G(v)=τ∑p∈Plog⁡p  p−τv1−p−τv.\frac{d}{dv}\log G(v) = \tau \sum_{p\in P} \frac{\log p\;p^{-\tau v}}{1-p^{-\tau v}}.dvd​logG(v)=τp∈P∑​1−p−τvlogpp−τv​.

Expanding the denominator gives

ddvlog⁡G(v)=τ∑p∈P∑k≥1(log⁡p)p−kτv.\frac{d}{dv}\log G(v) = \tau \sum_{p\in P} \sum_{k\ge1} (\log p)p^{-k\tau v}.dvd​logG(v)=τp∈P∑​k≥1∑​(logp)p−kτv.

This is a finite-prime analogue of

−ζ′(s)ζ(s)=∑p,k≥1log⁡ppks=∑n≥1Λ(n)ns.-\frac{\zeta'(s)}{\zeta(s)} = \sum_{p,k\ge1} \frac{\log p}{p^{ks}} = \sum_{n\ge1}\frac{\Lambda(n)}{n^s}.−ζ(s)ζ′(s)​=p,k≥1∑​pkslogp​=n≥1∑​nsΛ(n)​.

So each gated neuron or parameter block receives a gradient correction shaped like a truncated prime-power spectrum.

Arithmetic Feature Grammar#

Prime-indexed parameters also suggest a factorization grammar for neural features.

Atomic channels are assigned primes:

pi=atomic feature.p_i=\text{atomic feature}.pi​=atomic feature.

Composite interactions are represented by products:

pipj=pairwise interaction,p_ip_j=\text{pairwise interaction},pi​pj​=pairwise interaction, pipjpk=higher-order interaction.p_ip_jp_k=\text{higher-order interaction}.pi​pj​pk​=higher-order interaction.

Prime powers represent repeated self-interactions:

pik=repeated self-interaction.p_i^k=\text{repeated self-interaction}.pik​=repeated self-interaction.

This mirrors the logarithmic derivative of the Euler product:

−ζ′ζ=∑p,klog⁡ppks.-\frac{\zeta'}{\zeta} = \sum_{p,k} \frac{\log p}{p^{ks}}.−ζζ′​=p,k∑​pkslogp​.

The architectural claim is that a network can separate atomic features, pairwise composites, and higher-order interactions using the arithmetic topology of primes and composites.

Practical Design#

A concrete layer-level design is

hl+1=∑i=1mpi−τvl⋅σ(Wl,ihl).h_{l+1} = \sum_{i=1}^{m} p_i^{-\tau v_l} \cdot \sigma(W_{l,i}h_l).hl+1​=i=1∑m​pi−τvl​​⋅σ(Wl,i​hl​).

Add a budget penalty:

Ω=λ∑i(log⁡pi)α∥Wl,i∥F2.\Omega = \lambda \sum_i (\log p_i)^\alpha \|W_{l,i}\|_F^2.Ω=λi∑​(logpi​)α∥Wl,i​∥F2​.

This makes high-prime parameter blocks more expensive. The model learns to use small-prime blocks unless large-prime blocks are necessary.

PyTorch Sketch#

import torch
import torch.nn as nn
import torch.nn.functional as F


class PrimeEulerGate(nn.Module):
    def __init__(self, primes=(2, 3, 5, 7, 11), tau=3.0, eps=1e-6, max_val=1e6):
        super().__init__()
        self.register_buffer(
            "log_primes",
            torch.log(torch.tensor(primes, dtype=torch.float32)),
        )
        self.tau = tau
        self.eps = eps
        self.max_val = max_val

    def forward(self, z):
        v = F.softplus(z)
        terms = 1.0 - torch.exp(-self.tau * v.unsqueeze(-1) * self.log_primes)
        gate = torch.prod(terms, dim=-1)
        return torch.clamp(gate, self.eps, self.max_val)


class PESiLU(nn.Module):
    def __init__(self, primes=(2, 3, 5, 7, 11), tau=3.0):
        super().__init__()
        self.gate = PrimeEulerGate(primes=primes, tau=tau)

    def forward(self, z):
        return F.silu(z) * self.gate(z)


class ResidualPESiLU(nn.Module):
    def __init__(self, primes=(2, 3, 5, 7, 11), tau=3.0, alpha=0.1):
        super().__init__()
        self.gate = PrimeEulerGate(primes=primes, tau=tau)
        self.alpha = nn.Parameter(torch.tensor(float(alpha)))

    def forward(self, z):
        return F.silu(z) * (1.0 + self.alpha * self.gate(z))

Claim#

Prime Euler gated activations introduce a multiplicative spectral modulation whose log-gradient is a finite von Mangoldt expansion. This creates hierarchical activation sensitivity while preserving a stable base nonlinearity.

In one line:

Multiplicative PINN gates can become activation-level observer kernels.\boxed{ \text{Multiplicative PINN gates can become activation-level observer kernels.} }Multiplicative PINN gates can become activation-level observer kernels.​
